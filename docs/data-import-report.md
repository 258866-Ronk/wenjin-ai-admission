## 4. 来源质量

全部 31 条事实均带 `official-*` 来源质量标记。包括省级控制线、北京官方一分一段、学校官网分专业录取、以及教育部平台转载的特殊路径计划。学校官网“最低分换算位次”与“学校直接公开最低位次”通过 cautions 和 quality 字段区分，不将换算值包装成真实录取最低位次。

## 5. 数据边界

- 广东/江西 2026 控制线仅用于资格提示，不能生成学校或专业推荐。
- 西藏对口高职征集计划为特殊路径历史快照，不进入普通本科推荐。
- `rankUnavailable=true` 与 `scoreOnly=true` 的记录保持位次为空。
- 数据筛选自参考 ZIP 的公开 JSON，原始 ZIP 未修改；正式商业发布前仍需逐条完成许可证与来源使用权审计。

## 6. 重复和失败策略

稳定业务键命中且 checksum 相同计为重复；业务键相同但 checksum 变化执行 UPSERT 更新。单条解析失败写 `import_failures`，不阻断同批其他记录。后台导入把聚合统计写 `import_batches`；CLI 在终端输出 `IMPORT_RESULT`。
