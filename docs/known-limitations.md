# 已知限制

## 已实现但覆盖有限

- 演示数据由 31 条主数据和 10 条福建历史补充数据组成，仍不是全国院校专业全集。
- 规则引擎实现了 MVP 常见规则，但单科要求、身高、复杂体检、专项资格等需先导入结构化规则才能判断。
- Profile Extractor 是确定性中文抽取加模型接口，并非所有口语表达都能一次识别；低置信信息应由用户确认。
- 网页模型配置当前支持 OpenAI-compatible `/chat/completions` 协议；厂商专有 Responses API、签名认证和非标准请求格式需要新增适配器。
- 风险引擎覆盖核心梯度问题，不等同于每省正式志愿数量、平行志愿排序和调剂规则模拟器。
- 启动恢复使用档案快照和锁定数据版本重新执行确定性节点；尚未实现任意节点精确续跑和依赖图增量缓存。

## 尚未完整实现

- 自动 embedding、知识上传、pgvector 相似度召回和按元数据过滤的完整 RAG 管线；目前有表、索引迁移、来源证据和边界设计。
- 独立 `recommendations/{id}`、`recommendations/{id}/refine` 资源 API；推荐通过运行和报告读取。
- 独立手工志愿表持久化与 `GET /volunteer-plans/{id}/risks`；报告生成内的整表风险是真实实现，`POST /volunteer-plans/check` 仍为说明性入口。
- 报告局部 section 重写；当前 refine 指引用户在原会话调整条件并生成新报告。
- AI token/cost 的专用管理员接口；Micrometer 指标和模型调用基础日志已存在。
- 自动浏览器 E2E CI；已完成前端 lint/build、后端 HTTP 端到端测试和交互式浏览器检查。

## 环境限制

- Docker Compose 的 PostgreSQL/pgvector、Redis、Spring Boot 和 Next.js 已实际运行；本轮 Testcontainers 的 Ryuk 镜像无法从 Docker Hub 拉取，因此 1 项基础设施测试按设计跳过。
- 第一次部署需要下载基础镜像；镜像站短暂 TLS 超时时一键脚本会最多自动重试 3 次，但持续网络中断仍会阻止首次构建。
- 本地默认 Mock LLM，所以报告状态为 DEGRADED；这表示解释模板降级，不表示规则、候选或证据失败。
- H2 用于开发便利，不具备 PostgreSQL pgvector；真实向量能力必须用 Docker/PostgreSQL profile。

## 数据与业务限制

- 历史分数/位次不能代表下一年录取结果；招生计划、章程和政策会变化。
- 学校官网按最低分换算的一分一段位次不等于学校真实录取最低位次，系统在 cautions 中保留此差异。
- 特殊路径数据只用于对应资格提示，不进入普通批推荐。
- 正式发布/商业使用前仍须逐条完成数据许可证、转载条件和来源链接可用性审计。

## 明确禁止

系统不会代替用户登录考试院、自动提交志愿、绕过验证码或反爬、输出“保录/必中”、伪造概率、克隆第三方人物形象或声音。
