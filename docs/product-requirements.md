# 产品需求说明

## 1. 产品定位

问津智愿 AI 面向高考生和家长，提供“对话建档—数据查询—硬规则校验—冲稳保分层—整表风险—结构化报告—证据核验”的辅助决策流程。系统不代替考试院，不自动提交志愿，不承诺录取，也不输出未经校准的精确录取概率。

## 2. MVP 用户

- 游客：无需注册即可体验建档和报告，数据由匿名账号隔离。
- 注册用户：保存档案、历史会话和报告。
- 管理员：查看数据质量、运行诊断、导入 JSON 数据，并通过网页配置和测试大模型 API。

## 3. 核心用户故事

1. 用户输入省份、年份、分数/位次、选科、批次与偏好，系统自动抽取为版本化档案。
2. 信息不足时系统只追问一个最关键字段，不生成虚假推荐。
3. 信息完整后系统锁定数据版本，从数据库生成候选并先执行硬过滤。
4. 用户看到高冲、普通冲、偏稳、稳妥、保底，而不是伪精确概率。
5. 每个候选显示来源、年份、分数/位次语义、预算和风险；缺失位次时明确显示未公开。
6. 用户可刷新或切换历史会话，继续查看此前报告和证据。
7. Redis 或 LLM 不可用时仍可完成确定性分析，并明确显示降级状态。

## 4. 功能范围与验收

| 能力 | MVP 验收标准 |
|---|---|
| 身份 | 注册、登录、退出、游客、HttpOnly Cookie、管理员鉴权 |
| 建档 | 关键字段完整性、字段来源与置信度、手工修改 |
| 数据 | 至少 3 省演示覆盖，数据类型与来源语义不混用 |
| 推荐 | 候选来自数据库，硬规则先于排序，阈值配置在数据库 |
| 风险 | 至少检查保底不足、冲刺过多、位次/计划缺失、学校集中 |
| 报告 | JSON 结构、三种策略、证据、规则、免责声明、版本 |
| 异步 | 持久任务、checkpoint、Redis consumer group、本地回退、SSE 回放 |
| 前端 | 桌面三栏、移动端 Tab、报告/来源/档案/后台页面、管理员模型 API 配置 |
| 运维 | Compose、健康检查、Swagger、metrics、Trace ID |

## 5. 非功能要求

- 安全：Key 后端化与 AES-GCM 密文保存、BCrypt、限流、输入长度限制、CORS、管理员权限、错误脱敏。
- 一致性：任务开始时锁定档案快照与数据版本；幂等键防止重复任务。
- 可恢复：每节点 checkpoint；未完成任务启动恢复；SSE 事件落库。
- 可解释：关键候选关联 `evidenceIds`、`ruleResultIds`、`sourceIds` 和 `datasetVersion`。
- 可部署：本地 H2/Mock 零依赖启动；Docker 使用 PostgreSQL、pgvector、Redis。

## 6. 明确不做

收费支付、自动官方填报、登录考试院、绕过验证码/反爬、人物声音或形象克隆、录取承诺、全国特殊招生完全自动化。当前自动向量化 RAG 和完整手工志愿表持久体检也不在已验证 MVP 内，见 `known-limitations.md`。
